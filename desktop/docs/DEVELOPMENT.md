# Pi Desktop 开发记录

更新时间：2026-11-13（Asia/Hong_Kong）。当前版本为 0.7.1，resources/prompts、编辑重发与 Fast 已于 11 月 12 日完成正式包验收并部署。

## 目录与事实来源

- `D:\PI-SmalJcat`：Git 源码仓库，包含当前功能与测试。
- `D:\PI`：本机 Pi 运行环境，快捷方式与 Windows 桌面快捷方式统一指向 `%LOCALAPPDATA%\Programs\Pi Desktop\fdea6c4\Pi Desktop.exe`。
- Windows 桌面快捷方式实际指向 `%LOCALAPPDATA%\Programs\Pi Desktop\fdea6c4\Pi Desktop.exe`；本机交付必须同步核对这个安装目录。
- 本文件是当前状态总览；其他按阶段命名的文档是历史记录，其中的“尚未实现”可能已被后续阶段完成。
- 发布程序以 `release/tauri/release.json` 的版本、SHA-256 和 `source` 为准，不能只看 package.json。验收 JSON 中的程序哈希必须与待交付程序相同。

## 已实现并接入界面

- 对话：流式消息、附件与文件引用、会话恢复与冲突保护、上下文压缩及配置、用户消息复制与编辑、助手回复复制。
- 项目侧栏：项目分组、会话置顶/归档/恢复、项目菜单、自定义名称、置顶项目、分区管理及隐藏/恢复；本机保存整理状态，不删除会话文件。详见 [项目侧栏](PROJECT-SIDEBAR.md)。
- Antigravity：官方 CLI 已有登录接入、独立对话与历史、模型/推理配置、工具权限和取消；通过 ACP 管理子进程。
- 审阅：工作区文件预览、Git 暂存/未暂存差异、独立审阅窗口与引用回主窗口。
- 子代理：四种内置角色、队列与取消、重试和继续、可写角色独立 worktree、角色选择与逐项移除工作树；历史检索分页、完整 Unicode 结果分页、归档恢复。
- 索引：任务记录自动同步到 SQLite；会话正文 FTS5 trigram 检索、短词回退、多词 AND、工作区/时间过滤、搜索前增量同步、命中导航。
- 本机体验：命令运行器与进程树取消、托盘、登录启动、系统通知、两栏设置、主题/排版/快捷键偏好、本地崩溃诊断、存储统计及保留策略。
- 发布：下载校验与暂存更新、清单 Ed25519 签名、NSIS 构建；0.5.0 新增构建来源记录和本地部署/回退工具。

## 部分完成与边界

- 扩展：只做 manifest / 签名 / 权限信息检查；不是插件安装或加载系统，不能阻止 Pi 自身加载未签名扩展。
- MCP：桌面可连接 stdio / HTTP 服务并发现、调用工具；HTTP 复用会话 ID、发送初始化通知、读取 JSON/SSE 响应并维护 GET 通知流，工具列表变更使缓存失效。开发分支新增 resources/templates/prompts 分页浏览、资源读取和提示词获取，详见 [内容接口](MCP-CONTENT.md)。
- MCP Apps：独立 WebView、授权校验和审计已实现；资源仍来自 `fixture_catalog`，能力返回 `mock_result`，不是完整第三方 App 宿主。
- 命令运行器不支持交互式 PTY；没有浏览器自动化、WebMCP 和 Office/LaTeX 工件系统。
- 角色工具白名单与 worktree 不是 OS 沙箱。`verifier` 能执行 shell，不能把界面“不可修改文件”理解为操作系统强制只读。
- 安装器尚未实际安装验收；远端更新未端到端验证；没有 Authenticode 签名、跨平台发布或完整可访问性验收。

## 2026-11-10：MCP HTTP 会话与通知

- Streamable HTTP 保存初始化响应的会话 ID，并在后续 POST、GET、DELETE 携带会话头与协商协议版本。初始化成功后发送 `notifications/initialized`；无状态服务及 GET/DELETE 返回 405 均可兼容。
- POST 按请求 ID 匹配 JSON 或 SSE 结果，支持多行 data、CRLF、UTF-8、通知先到及结果后连接仍保持。GET 持续接收通知，断流后退避重连并携带最后事件 ID；断流和重新建流均使工具缓存失效，防止未重放的变更遗漏。
- `notifications/tools/list_changed` 使缓存失效，下次列工具时重新读取；没有自动刷新已展开面板。过期 404 取消该连接中的请求并显示未连接；失败的工具调用不重试，下一次显式操作可创建新会话。连接建立与断开串行，避免断开后旧握手重新插入。
- curl 子进程在超时、断开、会话析构时终止；正常断开尽力 DELETE 会话。URL、认证头和正文通过 stdin 配置传递，关闭 URL globbing 和自动重定向；响应头、行、事件及 JSON 正文有大小上限。
- 本轮只处理 tools 通道；resources/prompts、服务端请求（sampling/elicitation 等）、OAuth 及传统 HTTP+SSE 双端点仍未实现。GET 断流恢复依赖服务端是否支持事件重放，不自动重放 POST 或工具调用。
