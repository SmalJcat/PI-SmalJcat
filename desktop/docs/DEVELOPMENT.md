# Pi Desktop 开发记录

更新时间：2026-11-08（Asia/Hong_Kong）。当前开发版本：0.5.0。

## 目录与事实来源

- `D:\PI-SmalJcat`：Git 源码仓库，包含当前功能与测试。
- `D:\PI`：本机 Pi 运行环境，快捷方式指向 `desktop/release/tauri/Pi Desktop.exe`。
- 本文件是当前状态总览；其他按阶段命名的文档是历史记录，其中的“尚未实现”可能已被后续阶段完成。
- 发布程序以 `release/tauri/release.json` 的版本、SHA-256 和 `source` 为准，不能只看 package.json。验收 JSON 中的程序哈希必须与待交付程序相同。

## 已实现并接入界面

- 对话：流式消息、附件与文件引用、会话恢复与冲突保护、上下文压缩及配置。
- 审阅：工作区文件预览、Git 暂存/未暂存差异、独立审阅窗口与引用回主窗口。
- 子代理：四种内置角色、队列与取消、重试和继续、可写角色独立 worktree、角色选择与逐项移除工作树；历史检索分页、完整 Unicode 结果分页、归档恢复。
- 索引：任务记录自动同步到 SQLite；会话正文 FTS5 trigram 检索、短词回退、多词 AND、工作区/时间过滤、搜索前增量同步、命中导航。
- 本机体验：命令运行器与进程树取消、托盘、登录启动、系统通知、两栏设置、主题/排版/快捷键偏好、本地崩溃诊断、存储统计及保留策略。
- 发布：下载校验与暂存更新、清单 Ed25519 签名、NSIS 构建；0.5.0 新增构建来源记录和本地部署/回退工具。

## 部分完成与边界

- 扩展：只做 manifest / 签名 / 权限信息检查；不是插件安装或加载系统，不能阻止 Pi 自身加载未签名扩展。
- MCP：桌面可连接 stdio / HTTP 服务并发现、调用工具；HTTP 尚不复用 MCP session id，不维持服务端通知流；尚无 resources/prompts 桥接。
- MCP Apps：独立 WebView、授权校验和审计已实现；资源仍来自 `fixture_catalog`，能力返回 `mock_result`，不是完整第三方 App 宿主。
- 命令运行器不支持交互式 PTY；没有浏览器自动化、WebMCP 和 Office/LaTeX 工件系统。
- 角色工具白名单与 worktree 不是 OS 沙箱。`verifier` 能执行 shell，不能把界面“不可修改文件”理解为操作系统强制只读。
- 安装器尚未实际安装验收；远端更新未端到端验证；没有 Authenticode 签名、跨平台发布或完整可访问性验收。

## 2026-11-08：0.5.0 交付收尾

本轮接续原有未提交功能，统一版本，移除界面的旧版本 fallback。新增：

1. 构建前后计算源码指纹；构建失败或期间源码改变时拒绝暂存。清单包含提交、dirty 状态、指纹及范围。来源信息仅供诊断，不受 `pi-release-v1` 签名认证。
2. 本地部署仅复制程序、清单、可选图标；先校验副本，再切换目录，保留原发布目录。切换失败尝试自动恢复；显式指定 `--from` 可回退。
3. 拒绝重叠目录、并发部署、链接发布文件、损坏清单/程序，以及包含额外数据的目标目录。不会复制签名私钥或用户配置。
4. UI 验收父/子进程统一使用 PowerShell 7，增加单独的 release 验收命令。

本轮最终验证、程序哈希及本机部署结果见 [VERIFICATION.md](../VERIFICATION.md) 的 0.5.0 记录。

## 后续优先级

1. MCP HTTP 会话与通知协议补齐，接真实资源，为 MCP Apps 移除 fixture 铺路。
2. 插件安装/启停与加载前校验，明确与 Pi 原生扩展机制的责任边界。
3. 交互式 PTY；加强可写/执行型代理的边界、工作树生命周期与审阅合并体验。
4. 安装器和远端更新端到端验收；面向公开分发时再补代码签名。
