# 自绘图标体系 · 动效 · 界面精简

三件事一次做完：不再依赖第三方图标造型、补上克制的动效、收掉 ChatGPT 界面里没有的装饰模块。

## 一、自绘图标（`src/icons.tsx`）

设计规范（写在文件头，新增图标请照着来）：

- **24×24 网格**，可视区域留 2px 安全边；
- **描边统一 1.7px**，圆角端点 + 圆角连接；
- 只用直线、圆、弧，圆角半径 2px，同族图标共享比例；
- 一律 `currentColor`，尺寸由 `size` 属性控制（默认 16）；
- 统一 `aria-hidden`，图标不参与无障碍树，语义由文字承担。

工厂函数把每个图标压成一行，新增一个图标 ≈ 一行代码：

```tsx
export const Plus = draw(<><rect x="3.5" y="3.5" width="17" height="17" rx="4.5" /><path d="M12 8.5v7M8.5 12h7" /></>);
```

本批自绘 41 个：会话与导航（新建 / 搜索 / 侧栏收起展开 / 折叠 / 更多）、工作区与文件（文件夹 / 打开文件夹 / 分支 / 回形针）、对话操作（发送 / 停止 / 复制 / 关闭 / 新窗口打开）、功能入口（上下文 / 子代理 / 终端 / MCP / 扩展 / 更新 / 索引 / 设置）、状态与动作（刷新 / 完成 / 警告 / 加载 / 取消 / 运行 / 清空 / 技能 / 校验 / 盾牌 / 闪电 / 文件新增 / 外链 / 减号 / 双勾）。

**迁移方式**：`src/icons.tsx` 同时把尚未自绘的 8 个图标（`ArrowDown`、`ArrowUpRight`、`Code2`、`FileCode2`、`MessageSquare`、`RotateCcw`、`RotateCw`、`TerminalSquare`）从 lucide 转出，**12 个组件的导入已全部指向 `./icons`**。以后要替换任何一个，只需在 `icons.tsx` 里写好实现、把名字从转出列表里删掉，调用方零改动。

## 二、动效（全部挂在 chatgpt preset 下，可一键关掉）

| 动效 | 参数 | 说明 |
|---|---|---|
| 消息入场 | `pi-rise` 0.18s ease-out | 新消息上浮 5px 淡入；工具卡 3px / 0.14s |
| 流式进行中 | `pi-pulse` 1.1s 循环（三点错开 0.14s） | 呼吸点 |
| 流式光标 | `pi-caret` 1s step-end | 指示条后面的方块光标闪烁 |
| 交互过渡 | 0.14s 颜色/描边，输入台 0.16–0.18s 边框与阴影 | **只动颜色与阴影，不做位移**，避免长列表抖动 |
| 发送键按下 | `scale(0.94)` 0.12s | 轻反馈 |
| 弹窗 | 背景 `pi-fade` 0.14s、卡片 `pi-pop` 0.16s | 上浮 + 轻微缩放 |
| 命令菜单 / 下拉 / 提示条 | `pi-rise-sm` 0.12–0.14s | 从输入框上方浮出 |

`prefers-reduced-motion: reduce` 时**全部关闭**（沿用原约定），`forced-colors` 下不做额外处理。

## 三、界面精简（去掉用不上的装饰，保留功能）

| 去掉的 | 为什么 | 功能去哪了 |
|---|---|---|
| 标题栏中间的那句宣传语 | ChatGPT 没有，纯装饰 | 无（信息量为零） |
| 左上角 `LOCAL` 徽标 | 同上 | 无 |
| 空态里的大 π 徽标 | ChatGPT 用纯文字大标题 | 无 |
| 右侧面板底部的「在你的电脑上工作」卡片 | 占了面板高度、没有操作 | 无 |
| 建议卡片的三行结构（图标 + 标题 + 说明） | 落地页式，信息密度低 | **保留入口**：改成一行三个紧凑按钮，居中标题、去掉图标与说明 |

其余功能模块（上下文 / 子代理 / 终端 / 索引 / MCP / 扩展 / 更新 / 审阅面板）**一个没删**——它们是能力，不是装饰。

## 五、过程中的两个自伤与修复（记录在案）

1. **批量替换把 `icons.tsx` 自己的转出行也改成了 `./icons`**，形成自引用；已还原为 `lucide-react`。教训：批量替换要排除目标文件本身。
2. 修复时用 PowerShell 字符串替换**截断了 `icons.tsx` 的一行**（`Users2`），导致 `TS1005`；已定位删除该行并重建通过。教训：改源码用结构化编辑，不用正则裁剪。

另外：`tests/ui-theme.test.mjs` 增加了 `@keyframes` 步进选择器的豁免——否则 `from`/`to` 会被误判为未受作用域约束的选择器。
