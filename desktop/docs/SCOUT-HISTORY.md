# 探子历史管理：接口与数据保护

本地评审草案（随改动交接；未创建远程 issue / PR）。沿用 `agent-tasks` 命令，不新增通用文件或 shell 权限。

## 请求与响应

- `list`：保留无参数调用；新增 `query`（任务标题、模型、工作区、ID），`status`（all / active / completed / attention），`cwd`（可选精确工作区），`archive`（current / archived / all），`page`（从 1 开始）、`pageSize`（1–100；显式分页默认 20）。返回 `tasks, total, page, pageSize, totalPages, active, concurrency, warnings`。无分页参数仍返回最近 300 项，兼容父工具与原测试；用户界面使用显式分页。筛选先于分页，按 createdAt 降序、ID 升序稳定排序。
- `output`：`id, offset?`（UTF-8 字节位置）、`version?`（后续页必须沿用）。只读任务专属子会话，返回 `text, offset, nextOffset, totalBytes, version, source`。单页不超过 64 KiB，保持 UTF-8 边界；任务仍活跃或进程尚在收尾时拒绝。会话变更后拒绝旧版本分页，要求重载。只展示当前分支的 assistant 文本，不包含思考、用户消息或工具结果。无法读取完整会话时明确报错，不将截断预览冒充完整结果；无会话且预览未截断时可显示记录文本。
- `archive` / `restore`：`id`，返回更新后的 detail。新增可选持久字段 `archivedAt`，旧记录兼容。只归档已完成且进程已退出的任务；失败、取消、中断及活跃任务保留在当前列表。归档仅改变标记，不删除子会话、记录、锁或其他恢复数据；可恢复，先恢复再重试。

旧的 300 项启动读取上限移除，所有有效记录参与检索与恢复检查。单个记录仍受 1 MiB 限制；完整结果读取单个子会话上限 64 MiB，超限明确提示，不悄悄截断。历史量很大时启动读取仍随记录数量增加，后续可引入磁盘索引。

## 并发与路径保护

归档与启动、继续、取消共用管理锁，且同时检查任务状态和 jobs；先成功写盘再更新内存。恢复必须使用该任务 UUID 专属目录中的会话，不能引用其他任务或目录之外的会话，拒绝越界链接。重新打开时遗留活跃任务改为中断并取消归档，不自动发起模型调用。

列表和详情独立：翻页或搜索不取消运行任务；选择隐藏任务仍可查看详情。旧异步响应不能覆盖新筛选/新选择。完整结果按页查看，切换任务或重新运行后清空旧结果；复制和引用明确限于当前显示页。

## 清理设计（本阶段不执行永久删除）

归档不释放磁盘空间。永久清理需要单独实现并评审：先生成包含 ID、文件清单、大小和内容版本的预览；只允许已归档且已完成的任务；确认时重新验证状态、进程退出、会话锁及版本。任何 queued / starting / running / cancelling / failed / cancelled / interrupted 或可恢复任务必须排除。不得按模糊路径递归删除 agents 根目录、父会话、其他任务、锁目录或符号链接目标。优先同卷移入可恢复的隔离目录，恢复期满后再由用户明确选择永久删除；不做启动自动清理。此版本无删除 API 或清理按钮，避免把“归档”误认为“删除”。

## Windows 验收增量

运行 `npm run check:windows`；核对与云端相同的 `sources.json`。

1. 探子完成后搜索任务关键词；状态、当前工作区、归档筛选组合正确。跨页无重复，最后一页和空结果清楚，轮询不跳回第一页。
2. 点击完整结果，检查超过 128 KiB 的中文/emoji 文本尾部可见；下一页、上一页、复制当前页、返回预览可用；旧任务结果不会显示在新选择上。
3. 归档已完成任务后从当前列表消失、在已归档列表出现；恢复后原 ID / 会话内容不变。运行、取消收尾、中断任务不能归档；继续原会话仍有效。
4. 关闭重开后搜索与归档记录仍正确；超过 300 项的历史仍能查到。活动任务保持中断恢复行为，不自动调用模型。
5. 检查 UI 截图、渲染异常和所有测试 Pi 进程退出。
