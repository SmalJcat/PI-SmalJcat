# 界面偏好系统与外观面板（从 ChatGPT 设置移植有用的细分项）

## 一、移植了什么（每项都有真实逻辑，没有假开关）

| 设置项 | 取值 | 逻辑落点 |
|---|---|---|
| **界面风格** | ChatGPT 风格 / 赛博朋克 / 经典 | `data-ui` 标记，切换预设样式表 |
| **字号** | 紧凑 0.93 · 标准 1 · 宽松 1.07 · 大 1.14 | `--type-scale`，乘在排版令牌的**使用值**上（令牌基准不变） |
| **行高（中文正文）** | 1.6 / 1.75 / 1.9 | `--reading-line`，只影响中文正文，界面行高不动（避免按钮变形） |
| **字体** | 中文优先 / 系统默认 / 等宽 / 衬线 | `data-font-family` + 四套系统字体栈（不引入自有字体文件） |
| **圆角** | 方正 0.5 · 标准 1 · 圆润 1.4 | `--radius-scale`，乘在 8 个圆角令牌上（对应它的 `--corner-radius-scale`） |
| **对话宽度** | 窄 640 / 标准 768 / 宽 900 | `--chat-width` → `--column-width`（区间对应它 compact 640 / 展开 900） |
| **动效** | 完整 / 精简 / 关闭 | `data-motion`：精简去掉位移只留淡入，关闭停用全部动画与过渡 |
| **Enter 发送** | 开 / 关 | 关掉后 Enter 换行、Ctrl/Cmd+Enter 发送；**输入框底部提示同步切换** |
| **工具卡默认折叠** | 开 / 关 | 工具卡 `<details>` 的初始展开状态；默认**开**（与应用既有行为一致） |

另外把它的 **`--spacing: .25rem` 网格**做成我们的间距阶梯：`--space-1…10 = 4/8/12/16/20/24/32/40px`，设置面板已改用阶梯，新样式一律用阶梯而不再写孤立数值（对应你要的"层次与间距成套化"）。

**没有移植的**（需要额外工程，如实列出）：开机自启、最小化到托盘、通知、快捷键自定义、账号/用量、语言切换（本应用目前只有中文）。

## 二、实现结构

| 文件 | 职责 |
|---|---|
| `src/preferences.mjs` | 纯数据 + 纯函数：选项组、默认值、逐项校验回落、读写存储、折算 CSS 变量与 data 标记 |
| `src/typography.css` | 消费 `--type-scale` / `--reading-line`，并提供四套字体栈变体 |
| `src/chatgpt-theme.css` | 消费 `--radius-scale` / `--chat-width` / `data-motion` / 间距阶梯 |
| `src/SettingsDialog.tsx` | 外观分区渲染 9 项控件（分段控件 + 开关） |
| `src/components.tsx` | 工具卡初始折叠状态读偏好 |
| `src/App.tsx` | 启动即下发偏好；提交键与底部提示随偏好变化 |

**逐项校验**是关键设计：某个值非法时只回落该项，不清空用户的其他选择（有测试守着）。

## 四、这一轮验收抓到的两个真实问题（记在案）

1. **受控 `open` 与浏览器 toggle 打架**：我给工具卡加 `open={open} onToggle={...}`，挂载时的 toggle 事件把状态改成关闭，卡片永久收起。改法：放弃受控，用 `ref` 在挂载时设置一次初始状态，展开交给浏览器。
2. **默认值反转了既有行为**（更值钱的一个）：验收第 103 行是**点击工具卡摘要展开**，说明应用的既有契约是"默认收起、点击展开"。我的偏好默认写成"不折叠"，等于把默认行为反了——测试以 `locator.waitFor` 超时（63 次重试后元素仍为 hidden）暴露出来。

第 2 条尤其说明一件事：**新增偏好时，默认值必须等于原有行为**，否则用户（和测试）会立刻感到"东西不见了"。已把默认值改回"折叠"并把断言对齐。

另外修了一个命名撞车：设置面板里已有 Pi 的 `preferences`（可执行文件/工作区），我又加了同名的 UI 偏好，触发 `Duplicate identifier`；已把 UI 偏好改名 `uiPreferences`，并做了"零残留引用"自检。

## 五、验证缺口（诚实说明）

验收用例只打开了设置的**默认分区（连接）**，因此外观分区里 9 项控件的**运行时渲染**没有专门断言——目前靠 TypeScript 编译通过 + 设置弹窗能打开来保证。下一步可以补一条：打开设置 → 切到外观 → 断言 9 个控件存在且点击后 CSS 变量真的变化（这是端到端最该补的一环）。
